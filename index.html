What is the OSI Model?

The OSI (Open Systems Interconnection) model is a conceptual framework that standardizes network functions into seven layers. It helps to understand where protocols and tools operate.

The 7 Layers

Application

Interfaces for end-user applications — HTTP, FTP, SMTP, DNS. This is where application services live.

Presentation

Transforms and encrypts data; handles format translation and compression.

Session

Manages dialogs (sessions) and synchronization between applications.

Transport

End-to-end communication: segmentation, flow control, reliability (TCP/UDP).

Network

Routing, IP addressing and packet forwarding across networks.

Data Link

MAC addressing, frame formatting, and error detection on local links.

Physical

Physical media, electrical/optical signals, connectors and raw bit transmission.
